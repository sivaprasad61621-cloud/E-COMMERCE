# Velora AI PRD

## AI-Powered Contextual Shopping Assistant using RAG

### Overview

Velora AI integrates a Retrieval-Augmented Generation (RAG) shopping
assistant into the existing Velora e-commerce platform.

## Objectives

-   Intelligent shopping assistant
-   Product-aware AI chat
-   Document-based question answering
-   Conversational memory
-   Admin knowledge management

## Core Features

-   AI Chat Widget
-   Product Search using RAG
-   FAQ & Policy Assistant
-   Product Recommendations
-   Order Tracking
-   Admin Document Upload
-   Conversation Analytics

## Tech Stack

-   React + Vite + TypeScript
-   Tailwind CSS
-   Node.js + Express
-   Supabase PostgreSQL
-   Pinecone
-   LangChain.js
-   OpenAI-compatible LLM
-   Hugging Face Embeddings

## Architecture

Customer -\> Chat Widget -\> Express API -\> LangChain -\> Pinecone -\>
LLM -\> Response

## Development Phases

1.  Foundation
2.  Knowledge Base
3.  AI Assistant
4.  Admin AI
5.  Production & Deployment
